# Python Notebooks 
This repository contains Python notebooks developed to practise Python programming, data visualisation, and decision-support frameworks. 

## Projects 

### Eisenhower Matrix 
A Python-based tool for prioritising tasks according to urgency and importance. 

### Stress Management Matrix
A visual framework that maps stress levels against the ability to influence outcomes, helping focus attention on actionable issues.

- Python
