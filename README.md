# Python Notebooks 
This repository contains small practice projects and notebooks that help me develop skills in programming, data visualisation, and analytical problem-solving. The goal is simple: keep learning, keep building, and gradually turn curiosity into capability :) 

## Projects 

### Eisenhower Matrix 
A Python-based tool for prioritising tasks according to urgency and importance. 

### Stress Management Matrix
A visual framework that maps stress levels against the ability to influence outcomes, helping focus attention on actionable issues.
